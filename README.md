# TMDrive Auto

Android-помощник для фильтрации заказов по пользовательским условиям.

## Текущий этап
Начальный каркас Android-приложения: экран настроек, минимальная стоимость и редактируемые ключевые слова. Пока нет интеграции с TMDrive, распознавания карточек заказов, автоматического принятия заказов или готового APK.

## Требования
- Android Studio (JDK 17)
- Android Gradle Plugin 8.7.3
- Kotlin 2.0.21
- Минимальная версия Android: 8.0 (API 26)

## Безопасность и ограничения
Приложение не обходит защиту TMDrive и не выполняет скрытые нажатия. Любое дальнейшее взаимодействие с интерфейсом TMDrive должно соответствовать правилам сервиса и оставаться под контролем пользователя.
